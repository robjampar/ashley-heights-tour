# Follow-up fixes after the structural cleanup

## Navigation

Resident destinations now require real floor support and collision-free standing space. Furniture destinations try clear perimeter approaches and sample the entry path against walls and other obstacles, excluding only the furniture being used. Unusable destinations are omitted; camera shortcuts and model geometry are unchanged. This fixes destination points obstructed by the updated room furniture, including the formal dining arrangement.

Tests require every selected destination to be clear and supported, and validate the full entry segment for both Proposed and Planning. The earlier 85% threshold was strengthened, not relaxed.

Web suite: 125/125 passed. Local web build passed and updated `walkthrough/dist/`.

Path changes preserve approval hashes; substantive proposal changes still require review again.

Added tests for inventory reload, old source links, allowlist enforcement, approval preservation and restart workspace identity. `Restart improvement review.command` restarts only a server identifying itself as this workspace, then opens the board. Refresh older browser tabs after restarting.

## Native/runtime limit

Blender was tested with `--background --factory-startup` and no house file. It exited with SIGSEGV before running Python. Blender's own backtrace (`logs/fix-blender-crash.txt`) passes through Metal capability detection (`supports_barycentric_whitelist`, `metal_is_supported`); the owner's normal interactive launch works. This narrows the issue to startup in this launch context, but does not establish a complete causal diagnosis. Further identical launches were stopped.

The session also rejects loopback binding with `Operation not permitted`. The existing review server was left running; its new source code cannot take effect until it is restarted outside this restricted session. No alternate tool was used to bypass that restriction.

Prepared a read-only `Verify native models.command` launcher and `scripts/maintenance/verify_native_models.py`. It checks native opening, external assets and unchanged hashes in a separate Blender process. It does not rebuild or save the models. This native check remains unexecuted successfully.

No publication, Git commit or native design edits were performed.
