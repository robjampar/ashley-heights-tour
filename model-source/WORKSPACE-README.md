## Open the project

## Everyday commands

Run `make help` from this folder. Common commands:

```sh
make build-web      # rebuild the local viewer
make build-structure # update structural register and UK experimental trials
make build-visuals  # regenerate proposal visual assets after model/layout changes
make preview        # open the proposed design locally
make review         # open the owner review board
make test-python
make test-web
make check-layout
```

Full model rebuilds use `.venv/bin/python scripts/build/regenerate_design_outputs.py --help` and the launchers. They take longer and may replace generated outputs. See [the workspace guide](docs/WORKSPACE.md) before rebuilding or publishing.

The Proposed and Planning walkthroughs include the restored authored oak and fabric materials, baked directional daylight, refined upholstery, brighter interior fixtures, a visible sun aligned with live shadows, local reflections and a natural camera lens. There is one detailed licensed Tesla Model 3 and one modern Fiat 500 Abarth on the front drive, with one Nissan NV200 van inside the garage, all at real scale; attribution is available in Settings → 3D model credits. Use **Settings → Camera lens** for wider views, or **H** to hide the interface (**Esc** restores it). The visual build saves editable derivatives under `outputs/output-visual-realism-{compact,planning}/`; then run `make build-web` to update the local viewer.

**This folder is the working model workspace, not the publishing Git checkout.** The independent repository is `deployment/ashley-heights-tour`. A Git command run here otherwise finds the unrelated parent repository. Publishing is a separate explicit action.

Detailed design and pipeline notes are preserved in [Project history](docs/PROJECT-HISTORY.md).
